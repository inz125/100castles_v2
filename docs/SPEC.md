# 100名城スタンプ帳 仕様（MVP）

## 目的

日本100名城をめぐるための iPhone 向け PWA。

利用シーンの優先順位：

1. **記録帳**（押印記録・進捗）← MVP
2. 旅の計画（次に行く城を探す、アクセス確認）
3. 現地で使う（スタンプ設置場所、見どころ）

## 対象

- 日本100名城の100城のみ（続日本100名城は対象外）

## 城マスタデータ

アプリに同梱する読み取り専用の JSON。

| 項目     | 型               | 例                 |
| -------- | ---------------- | ------------------ |
| 番号     | number（1〜100） | 1                  |
| 城名     | string           | 根室半島チャシ跡群 |
| 都道府県 | string           | 北海道             |
| 地方     | string           | 北海道             |

## 記録データ（城ごと）

| 項目     | 型                          | 備考                                         |
| -------- | --------------------------- | -------------------------------------------- |
| 押印済み | （押印日から導出）          | 押印日があれば押印済み。独立した値は持たない |
| 押印日   | string（YYYY-MM-DD）\| null | 押印済みのときのみ値を持つ                   |
| メモ     | string                      | 自由記述                                     |

### ルール

- 押印済みを ON にすると、押印日に今日の日付を自動で設定する（あとから変更可）
- 押印済みを OFF にすると、押印日を消去する
- 不変条件：`押印済み ⇔ 押印日が存在する`

## 画面

### 一覧画面

- 画面上部に全体の進捗を表示（`xx/100`）
- 100城を地方ごとにグループ化し、番号順に表示
- 地方見出しに地方ごとの進捗を表示（例：`東北 3/12`）
- 絞り込み：`すべて` / `未押印` / `押印済み`
- 押印済みの城には朱色の印を表示
- 城をタップすると詳細画面へ遷移

### 詳細画面

- 押印済みの切り替え
- 押印日の編集
- メモの編集
- 変更は自動保存（保存ボタンなし）
  - 押印済み・押印日：変更した時点で保存
  - メモ：入力が止まって少し経ったとき（debounce）、または入力欄から離れたとき（blur）に保存

## 保存

- 端末内のみ（localStorage）
- 保存処理は Repository インターフェースで抽象化し、将来クラウド同期に差し替えられるようにする（非同期・城ごとに保存）
- 保存形式：`{ version: 1, records: { 城番号: 記録 } }`（記録がない城は未押印）
- 壊れたデータ：元のデータを `…backup-日時` に退避し、読める記録だけを使う（全体が読めなければ空の記録帳で始める）
- アプリが知らない新しいバージョンのデータ：データには触れず、「アプリを更新してください」と表示して記録の変更をできなくする
- 古いバージョンのデータ：読み込むときに今の形へ変換する（マイグレーション）
- 将来構想：クラウド同期で 2 人が 1 冊の記録帳を共有する

## PWA

- `name`：100名城スタンプ帳
- `short_name`：100名城
- オフライン対応（vite-plugin-pwa でアプリ本体をキャッシュ）
- ホーム画面に追加して使う前提（standalone 表示）

## デザイン

- 和風テイスト：生成り色（背景）・墨色（文字）・朱色（押印・アクセント）
- ダークモードは端末設定に合わせて自動で切り替える
- 装飾は控えめにし、配色を中心に表現する

## 技術構成

- Vite + TypeScript + React
- テスト：Vitest + Testing Library（TDD で開発）
- 公開先：GitHub Pages（GitHub Actions で自動デプロイ）
