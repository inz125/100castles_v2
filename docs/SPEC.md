# 100名城スタンプ帳 仕様

## 目的

日本100名城をめぐるための iPhone 向け PWA。

利用シーンの優先順位：

1. **記録帳**（押印記録・進捗）← MVP（公開済み）
2. **旅の計画**（次に行く城を探す：近い順の一覧・地図）← 公開済み
   - 2 人で 1 冊の記録帳を共有するクラウド同期 ← 公開済み
3. 現地で使う（スタンプ設置場所、見どころ）

## 対象

- 日本100名城の100城のみ（続日本100名城は対象外）

## 城マスタデータ

アプリに同梱する読み取り専用の JSON。

| 項目     | 型               | 例                 |
| -------- | ---------------- | ------------------ |
| 番号     | number（1〜100） | 1                  |
| 城名     | string           | 根室半島チャシ跡群 |
| 都道府県 | string           | 北海道             |
| 地方     | string           | 北海道             |
| 緯度     | number           | 43.3               |
| 経度     | number           | 145.6              |

- 緯度経度は城跡の中心付近（天守・本丸など）。公開情報をもとに用意し、ユーザーが確認する
- スタンプの設置場所は「現地で使う」機能で別データとして追加する

## 記録データ（城ごと）

| 項目     | 型                          | 備考                                         |
| -------- | --------------------------- | -------------------------------------------- |
| 押印済み | （押印日から導出）          | 押印日があれば押印済み。独立した値は持たない |
| 押印日   | string（YYYY-MM-DD）\| null | 押印済みのときのみ値を持つ                   |
| メモ     | string                      | 自由記述                                     |

### ルール

- 押印済みを ON にすると、押印日に今日の日付を自動で設定する（あとから変更可）
- 押印済みを OFF にすると、押印日を消去する
- 不変条件：`押印済み ⇔ 押印日が存在する`

## 画面

### 画面構成

- 画面下部のタブバーで「一覧」「近く」「地図」を切り替える
- 詳細画面は各タブから開き、「戻る」で開く前のタブ（画面）に戻る

### 一覧画面

- 画面上部（進捗の見出し）
  - 天守のシルエットを淡く背景に置き、中央に朱色の進捗リングを重ねる。リングの中央に `37 / 100` を表示する（達成率は表示しない）
  - その下に地方ごとの小さな進捗リングを横スクロールで並べる（地方名・`3/12`）
    - タップするとその地方の見出しまでスクロールする。絞り込みでその地方が表示されていなければ、絞り込みを `すべて` にしてからスクロールする
    - 制覇した地方（押印済み＝地方の城の数）は、リングが朱印風の「制覇」の印に変わる
  - 進捗の見出しと絞り込みの間を青海波の区切りで分ける
- 100城を地方ごとにグループ化し、番号順に表示
- 地方見出しに地方ごとの進捗を表示（例：`東北 3/12`）。制覇した地方には `制覇` の印を付ける
- 絞り込み：`すべて` / `未押印` / `押印済み`
- 押印済みの城には朱色の印を表示
- 城をタップすると詳細画面へ遷移

### 詳細画面

- 押印済みの切り替え（ON にした日は端末のローカル時刻の今日）
- 押印日の編集（今日より後の日付・空欄は受け付けない）
- メモの編集
- 制覇の演出：押印済みを ON にしたことで地方または 100 城が揃ったとき、演出を表示する
  - 地方を制覇：画面中央に朱印風の「〇〇 制覇」が少し回転しながら押され、2〜3 秒で消える。タップでも消せる
  - 100 城を制覇：「日本100名城 制覇」の大きな朱印が押され、桜の花びらが舞う。タップするまで残る（地方の制覇と同時なら 100 城の演出だけを出す）
  - 押印日やメモの変更、もう 1 人の変更（同期）では出さない。OFF にしてもう一度 ON にしたときは再び出す
  - 端末の「視差効果を減らす」が ON なら、動き（回転・花びら）を省いて表示する
- 変更は自動保存（保存ボタンなし）
  - 押印済み・押印日：変更した時点で保存
  - メモ：入力が 1 秒止まったとき、入力欄から離れたとき、アプリが隠れたとき、画面を離れるときに保存
- 保存に失敗したとき：「保存できませんでした」と表示する
  - 押印済み・押印日：画面を保存前の状態に戻す（画面と保存内容を一致させる）
  - メモ：書いた文字は残し、次の入力や入力欄から離れたときに保存し直す

### 近くタブ

- タブを開いたときに現在地を自動で取得し、「更新」ボタンで取り直せる
- 城を現在地から近い順に並べ、直線距離を表示する（例：`松本城 12km`）
  - 1km 未満は 10m 単位（`850m`）、10km 未満は小数 1 桁（`1.2km`）、10km 以上は整数（`12km`）。四捨五入して上の区分に届いたら上の区分で表示する
- 絞り込み：`すべて` / `未押印` / `押印済み`。選択は一覧タブとは別に覚えておき、初期値は `未押印`
- 位置情報が許可されていない・取得に失敗したときは、理由と対処（設定アプリから許可する等）を表示する
  - 取得中：「現在地を取得しています…」
  - 許可されていない：「位置情報の利用が許可されていません。iPhone の『設定』→『プライバシーとセキュリティ』→『位置情報サービス』→『Safari Webサイト』を『使用中のみ』にしてから、『更新』を押してください。」
  - 失敗：「現在地を取得できませんでした。電波の届く場所で『更新』を押してください。」

### 地図タブ

- 地図：Leaflet ＋ 国土地理院タイル（出典を表記する）
- 100 城すべてをピンで表示（絞り込みなし）。押印済みは朱色、未押印は墨色
- 現在地を取得できていれば青い点で表示する
- ピンをタップすると吹き出しで城名・番号・押印の状態を表示し、「詳細を見る」から詳細画面へ
- 前回見ていた位置と拡大率を覚えておく（初回は日本全体）
- 「現在地へ移動」ボタンで現在地の周辺を表示する
  - 地図タブを開いたときにも現在地を取得する（取得できなくても何も表示しない）
  - ボタンを押すと現在地を取り直し、市町村が見える程度（拡大率 12）以上に寄せて現在地に移動する
  - ボタンを押して取得できなかったときは、近くタブと同じ理由と対処を地図の上に表示する
- 電波がないと地図画像は表示されないが、ピンは表示される

## 保存

- 共有していないときは端末内のみ（localStorage）。共有中はクラウド（下記「クラウド同期」）
- 保存処理は Repository インターフェースで抽象化し、端末内とクラウドを差し替えられるようにする（非同期・城ごとに保存）
- 保存形式：`{ version: 1, records: { 城番号: 記録 } }`（記録がない城は未押印）
- 壊れたデータ：元のデータを `…backup-日時` に退避し、読める記録だけを使う（全体が読めなければ空の記録帳で始める）
- アプリが知らない新しいバージョンのデータ：データには触れず、「アプリを更新してください」と表示して記録の変更をできなくする
- 古いバージョンのデータ：読み込むときに今の形へ変換する（マイグレーション）

## クラウド同期（2 人で 1 冊の記録帳を共有）

### 始め方

- 共有は使いたいときだけ始める。始めるまでは今までどおり端末内だけで使う
- 入り口：一覧タブの見出し（アプリ名）の右上の「共有」ボタンから共有画面（`#/share`）を開く
- **共有を始める**：今の端末の記録をクラウドに上げて新しい記録帳を作り、共有コードを表示する
  - 共有コードは 12 文字（読み間違えやすい `0 O 1 I L` を除いた英大文字・数字）を `XXXX-XXXX-XXXX` の形で表示する（推測できない長さにする）
  - 「コピー」と、iPhone の共有シート（LINE などで送る）を用意する
- **共有に参加する**：もう 1 人が自分の端末で共有コードを入力して参加する
  - 大文字・小文字、ハイフン・空白の有無は区別しない
  - コードに合う記録帳がなければ「共有コードが見つかりません」と表示する
  - 参加する端末は、まだ記録をつけていない前提。記録が残っていた場合は消さずに端末内に退避し、共有の記録帳を使う
  - ホーム画面に追加したアプリと Safari は保存場所が別なので、参加はホーム画面のアプリで行う（共有画面に書いておく）
- 共有中の端末では、共有画面に共有コードを表示し、もう 1 人に何度でも伝えられる
- 共有をやめる機能は作らない（機種変更したときは新しい端末で同じコードで参加する）

### 同期

- もう 1 人の変更は、アプリを開いている間は自動で反映される（開き直さなくてよい）
- 電波がないときも今までどおり記録をつけられ、つながったときに自動で送る
- 同じ城を 2 人が同時に変えたときは、城ごとに後から保存したほうが残る
- 同期の状態を「共有」ボタンのところに小さく表示する（同期済み／送信待ち／オフライン）

### クラウドの構成

- Firebase（Cloud Firestore）の無料枠を使う。プロジェクトはユーザーのアカウントで作る
- ログインはしない。共有コードを知っている端末だけが読み書きできる
  - 記録帳の一覧は取得できないようにし、コードを知らないと記録帳にたどり着けないようにする
  - 保存できるデータの形（城番号 1〜100、押印日・メモ（1 万文字まで））をルールで制限する。記録帳・記録は削除できない
- 端末内のデータの保存形式・マイグレーションの考え方はクラウドでも同じにする（記録帳ごとにバージョンを持つ）

## PWA

- `name`：100名城スタンプ帳
- `short_name`：100名城
- オフライン対応（vite-plugin-pwa でアプリ本体をキャッシュ）
- ホーム画面に追加して使う前提（standalone 表示）

## デザイン

- 和風テイスト：生成り色（背景）・墨色（文字）・朱色（押印・アクセント）
- ダークモードは端末設定に合わせて自動で切り替える
- 一覧画面は城らしい装飾を加える：和紙風の淡い地模様、明朝体の見出し、かすれと枠のある朱印らしい印、青海波などの和柄の区切り、天守のシルエット
- ほかの画面は配色を中心に表現し、装飾は控えめにする

## 技術構成

- Vite + TypeScript + React
- テスト：Vitest + Testing Library（TDD で開発）
- 公開先：GitHub Pages（GitHub Actions で自動デプロイ）
- 地図：Leaflet ＋ 国土地理院タイル
- クラウド同期：Firebase（Cloud Firestore）

## 対象外（将来検討）

- 複数回の訪問の記録
- スタンプの設置場所・アクセス・見どころ（「現地で使う」機能で検討）
- 文字での検索
- データの書き出し/読み込み（JSON）
- 共有をやめる・3 人以上での共有
- 続日本100名城
